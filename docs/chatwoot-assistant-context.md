# AutoApply SA Support Context

Use this as the factual knowledge source for the AutoApply SA website chat.

## Product

AutoApply SA helps candidates organize a Saudi job search in one workspace. Candidates can create an account, upload a CV, review profile information, set job-search preferences, discover relevant opportunities, and follow real application activity when it is recorded in their account.

AutoApply SA does not guarantee an interview, a job offer, placement, a response from an employer, or a particular application volume.

## What Is Available Today

- Email and password account sign-up through the customer portal.
- CV upload and profile review.
- Candidate consent before campaign activity.
- Job discovery and application tracking when connected records exist.
- English and Arabic interfaces.
- Manual application organization and status visibility.

## Current Availability Boundaries

- Review First is coming soon ✨. It will let a candidate approve prepared applications before submission when the preparation service is connected.
- Smart AutoApply is coming soon ✨. It will only operate after a verified automation service and explicit candidate controls are connected.
- Google and GitHub sign-in are coming soon ✨ until the corresponding Supabase provider is enabled.
- The Chrome Companion is optional. It is a local Manifest V3 helper for supported high-confidence fields. It does not solve CAPTCHAs, handle MFA, access credentials, or submit applications automatically.

## Helpful Responses

### Getting started

Direct candidates to `https://app.hsndm.tech/sign-up` to create an account. Returning candidates can use `https://app.hsndm.tech/login`.

### Application status

Never invent a status. Explain that the account dashboard shows application activity only after the corresponding system record is created. Ask the candidate to sign in and open Applications to see their own history.

### Privacy

Candidates control their profile and consent. Do not ask for CV contents, passwords, verification codes, payment-card information, or identity documents in chat. Direct privacy questions to the Privacy page or the signed-in portal.

### Job guarantees and automatic applications

Be clear: AutoApply SA supports an organized search and candidate-controlled preparation. It does not promise employment and must not claim that an application was submitted, delivered, or reviewed unless the candidate's account shows that record.

### Escalation

If a question requires account-specific information, payments, a missing application record, a sign-in error, or technical diagnosis, ask the visitor to use the relevant signed-in portal page. Do not request secrets or personal documents in the chat.
