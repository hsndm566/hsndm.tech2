AutoApply SA developer documentation

This public REST API lets developers and agents read product information, public monthly plans, and the health of the catalogue API. It is read-only and contains no candidate information.

Authentication: no API key is required for these public GET endpoints. There are no public endpoints for CV uploads, candidate profiles, private applications, account changes, payments, or employer submissions.

Endpoints

MethodEndpointPurpose
GET/api/v1/healthRead the public catalogue API status and scope.
GET/api/v1/productRead product purpose, supported languages, capabilities, and current limits.
GET/api/v1/plansRead monthly plan names, prices in SAR, and feature summaries.

Example request

curl -sS -H "Accept: application/json" https://www.hsndm.tech/api/v1/product

Rate limits

Each edge instance limits each client IP to 60 requests in a rolling minute window. Responses include RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset, and RateLimit-Policy. HTTP 429 responses also include Retry-After. Cloudflare edge instances keep independent counters, so this is a best-effort per-instance limit rather than a global quota. Clients should reduce request frequency when remaining quota is low.

CLI source

A dependency-free Node.js CLI source package is included in the source repository. It can read these public resources. It has not yet been published to npm; use the repository instructions until the package is released.

Use limits

Do not send personal data to the public API. Do not represent the public product catalogue as an account integration. AutoApply SA does not currently submit applications to employers.
