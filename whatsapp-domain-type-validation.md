# WhatsApp Transition, English Type, and Domain Validation

The English reading-copy adjustment was reviewed at desktop and 375px mobile sizes. Supporting paragraphs now use a modestly larger scale while compact mono labels, navigation, and status details remain intentionally dense. The enquiry form remains readable and balanced at both widths.

The enquiry submission flow now opens a short in-page status treatment before it transfers to a prefilled WhatsApp message. The confirmation route remains intact, and users are explicitly told to attach the CV directly in the WhatsApp chat because a browser deep link cannot transmit the selected file.

The `hsndm.tech` DNS currently resolves to GitHub Pages, whose configured source is the repository’s `main` branch. The managed live project is published on `hsndmstudio-lyaavagg.manus.space`; mapping `hsndm.tech` to it requires changing the custom-domain routing in project settings and removing or changing the existing GitHub Pages source.
