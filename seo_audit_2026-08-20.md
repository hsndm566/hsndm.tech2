# AutoApply SA — Live SEO Audit

**Audited domain:** `https://www.hsndm.tech/`  
**Date:** 20 August 2026  
**Scope:** Live crawl directives, sitemap and redirect consistency, page metadata, structured data, topical focus, and available OpenSEO evidence.

## Executive assessment

The public site is technically reachable, uses HTTPS, returns indexable metadata on its representative final URLs, and already includes `Organization` and `Service` structured data. The strongest immediate technical gap is that the crawl directives still advertise the retired apex hostname and redirecting URL forms, while the site’s canonical host is `www.hsndm.tech`. The larger strategic gap is topical dilution: the main job-application offer is clear, but the indexable Services and Case Studies pages also present unrelated web/operations and airport-process material under the same domain.

> This is an evidence-led technical and content audit, not a ranking-position report. OpenSEO authenticated correctly, but its hosted site-audit request returned a provider-side `customer_not_found` error, the new project has no connected Search Console property, and the account reports zero OpenSEO credits. Therefore, live keyword positions, backlink counts, and Search Console query performance could not be verified in this run.

## Foundational measurement blocker

Before choosing target keywords or measuring the impact of the three priorities, connect the OpenSEO project to the verified Google Search Console property for `www.hsndm.tech`, and connect GA4 if it is in use. This does not directly improve rankings, but it enables query-level impressions, clicks, average positions, coverage/indexing inspection, and page-level opportunity analysis. OpenSEO’s project was created successfully, but Search Console is not yet connected and the provider’s site-audit backend was unavailable for this account during the audit.
