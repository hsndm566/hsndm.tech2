# Uptal Slider Reference

The observed Uptal slider is a single continuous numeric range control, not a multi-stage workflow selector. It has a clear three-part hierarchy: a dynamic headline that incorporates the selected value, one prominent calculated output, and a visible min/value/max scale. The supporting sentence tells the user exactly what changing the slider will do. The interaction is therefore appropriate for adjusting a single numeric variable, but not for moving between explanatory campaign stages.

For AutoApply SA, copying the visual rhythm without copying the semantic mismatch means either using a true range with a measurable campaign variable or replacing the current stage slider with direct segmented buttons. The latter is more reliable and understandable for three discrete campaign stages.
